# symphysis-vscode

Расширение VS Code для журнала решений symphysis.

Работа с ядром, подпись коммитов, что считается сменой контракта, пуш и пауза: `../symphysis/docs/repo-contract.md`. Копии здесь нет.

Замысел и решения: `docs/design-part1-viewer.md`.

Зависимости: можно добавлять любой пакет, если его можно получить в корпоративном хранилище или собрать самим, но лишние зависимости нежелательны (слово владельца 2026-11-05, снятие Р19).
