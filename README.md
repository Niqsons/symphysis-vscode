# symphysis-vscode

Компонент «плагин» схемы OpenSpec `symphysis`: расширение VS Code для журнала решений — развилки, слово
человека, внесение в журнал, схема решения и справка о шаге конвейера. Репозиторий — `symphysis-vscode`,
выпускается пакетом `.vsix`; README пакета — [docs/package-readme.md](docs/package-readme.md), упаковка
передаёт его `vsce`. Контракт с ядром — `docs/repo-contract.md` в репозитории ядра `symphysis-core`,
копии здесь нет.

## Каталоги первого уровня

- [docs/](docs/) — контур разработки: замысел первой части, итоги пробного запуска и README пакета
- [media/](media/) — контур разработки: значок пакета; сборка кладёт сюда страницы, стили и mermaid
- [src/](src/) — контур разработки: исходники, в нём лежат модули плагина `src/<модуль>/` — каждый со своим README, список ниже
- [test/](test/) — контур разработки: сквозные тесты, тесты нескольких модулей, общие помощники и фикстуры, проверка структуры
- [tools/](tools/) — контур разработки: списки допусков гейта имён

## Модули в `src/`

- [activation](src/activation/) — технический: активация расширения, связывает модули
- [changes](src/changes/) — доменный: дерево изменений в боковой панели и хранилище журналов
- [core](src/core/) — технический: поиск ядра и Python, вызовы `journal.py`, номер контракта
- [file-links](src/file-links/) — доменный: ссылки на файлы со страниц
- [hook](src/hook/) — доменный: хук агента и его скрипт `hook.py`
- [journal](src/journal/) — доменный: логика журнала на стороне плагина — выбор, правки черновика, атака
- [protocol](src/protocol/) — технический: сообщения хоста и страниц, данные `view-json`
- [scheme](src/scheme/) — доменный: вкладка схемы решения `scheme.md`
- [search](src/search/) — доменный: поиск в боковой панели
- [step-help](src/step-help/) — доменный: справка о шаге конвейера
- [ui](src/ui/) — технический: общие части страниц и панелей
- [viewer](src/viewer/) — доменный: просмотрщик журнала — карточки решений и внесение

## Сборка и упаковка

Файлы корня, не модуль. `build.mjs` собирает хост в `out/`, страницы — в `media/`, кладёт копию
`src/hook/hook.py` в `hook/hook.py` — путь, по которому её читает код, — и собирает юнит-тесты из
`test/unit/` и `src/<модуль>/test/`. `package.mjs` упаковывает `.vsix`. Выходы сборки в git не идут.
