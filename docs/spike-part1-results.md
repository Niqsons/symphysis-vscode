### Строгий режим

Текст схемы с опасными подписями: `<img onerror>`, `<script>`, `click … call`,
`click … href "javascript:"`, картинка с внешнего адреса.

| | `strict` | `loose` (контроль) |
| --- | --- | --- |
| Вызов функции по клику | нет | **да** |
| Ссылка `javascript:` | снята | **осталась** |
| `onerror` и `<script>` | сняты | сняты |
| Тег `<img>` с внешним адресом | остался, загрузку блокирует CSP страницы | то же |

Контроль показывает, что проверка отличает безопасное от опасного. Держат две
ограды: строгий режим и CSP. Без `style-src 'unsafe-inline'` страница не обходится:
mermaid вставляет стили в рисунок. На диаграмме последовательности CSP блокирует
встроенный скрипт самого mermaid; рисунок при этом цел.

## 4. Сохранение человека и запись агента

| Случай | События |
| --- | --- |
| Человек: правка и команда сохранения | `willSave:Manual`, `didSave`, watcher |
| Другое расширение: `document.save()` | `willSave:Manual`, `didSave`, watcher |
| Принятие diff: `WorkspaceEdit` и `document.save()` | `willSave:Manual`, `didSave`, watcher |
| Человек при автосохранении, 3 правки | 3 раза `willSave:AfterDelay`, `didSave`, watcher |
| Агент CLI пишет на диск, файл открыт | watcher, обновление документа |
| `workspace.fs.writeFile` | watcher, обновление документа |
| Скрипт Python пишет файл | watcher, обновление документа |
| Атомарная запись: временный файл и переименование | watcher, обновление документа |
| Удаление и создание | `watcher:delete`, `watcher:create` |

**Вывод: через API различимо «через редактор» и «мимо редактора», но не «человек»
и «агент».** Третья строка таблицы совпадает с первой, а Claude Code делает именно
так. В его `extension.js` (версия 2.1.314) `document.save()` вызывается при принятии
diff, по инструменту сохранения документа и перед запуском своего инструмента правки
(«Saving unsaved changes … before the … tool runs»). Живого агента в прогоне не было:
случай с diff воспроизведён тем же вызовом API.

Следствия для следящего кода: слушать надо и `change`, и `create`, и `delete`,
а сохранения при автосохранении склеивать.

для интерфейса: пока Python работает, на экране остаются прежние данные, ничего не блокируется.

## Поправки к прежним утверждениям

- Mermaid весит 5,4 МБ, не 2–3 МБ, как в прикидке.
- Подмена `python.exe`, записанная в дизайне как довод, подтвердилась, но первый
  прогон показывал обратное из-за переменной окружения среды агента.
- Р16 исходил из того, что сохранение человека можно отличить от записи агента.
  Нельзя.

## Что не проверено

- Как это выглядит и ощущается: окно прогона никто не разглядывал, нужен взгляд

```

node run.mjs iife full
```
