# Приёмка req-graph-viewer

## Проверенная реализация

Ядро проверено в `ff126cb9`, код плагина — в `b6c5a38`. Начальный переключатель «Только со связями» выключен. Список пропусков рассчитывается по всему изменению и имеет соответствующую подпись.

В 24 требования добавлены объявления implements. Просмотр живого изменения с выбором `symphysis-vscode/req-graph` вернул 107 узлов, 13 требований и 10 модулей контекста. Диагностика сборки пуста. Публичный вывод установленного runtime также проверен отдельной локальной установкой.

- C1 — ошибка, timeout и maxBuffer отказывают при частичном stdout, чувствительный stderr остаётся вне сообщения.

- C4 — настоящий путь проверяется при каждом открытии, смена junction наружу отклоняется.

## Обзор

Выполнен независимый read-only обзор исходников двух repo по specs, design и security. Замечание об общей ошибке исчезнувшего требования исправлено через C3. Дополнительные проверки автора закрепили отсечение кандидатов вне implements, произвольный каталог снимка, узкую область рисунка, архивный контекст и отсутствие связи с решением при ребре к модулю. Все эти изменения прошли RED → GREEN.

## Локальная проверочная среда

Проверки выполнены на Windows с Python 3.13 и xdist, Node 24 и отдельным VS Code 1.145.3. Зависимости и тестовый VS Code размещены на диске X после нехватки места на C. Для проверки кода установленного VSIX в Test mode в его временную установку добавлен водитель страницы. Сам пакет проверяется отдельным прогоном в обычном режиме расширения.
