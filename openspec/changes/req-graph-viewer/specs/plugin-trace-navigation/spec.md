# Spec Delta

## Purpose

Переходы из диаграммы req-graph к записям журнала и исходным артефактам. Поддержка кликов ограничена решением F-18.A: она не требует сложных модификаций графа или артефактов ради навигации.

## ADDED Requirements

### Requirement: Узел записи ведёт к соответствующей записи журнала
Для поддержанных переходов выбор узла записи SHALL открывать соответствующую запись в просмотрщике журнала. Цель SHALL определяться по соответствию исходному узлу из ответа ядра (F-18.A, F-19, F-23.A).

#### Scenario: Переход к развилке
- **GIVEN** выбранный элемент диаграммы соответствует доступной записи журнала
- **WHEN** человек нажимает на этот элемент
- **THEN** просмотрщик показывает соответствующую запись

#### Scenario: Переход дожидается данных журнала источника
<!-- F-43 -->
- **GIVEN** просмотрщик закрыт, ещё загружается или показывает другой журнал
- **WHEN** человек нажимает на доступную запись графа
- **THEN** открывается журнал источника и переход выполняется после готовности его данных, одноимённая запись другого журнала не выбирается

### Requirement: Узел артефакта ведёт к исходному месту
Для поддержанных переходов выбор узла артефакта SHALL открывать соответствующий исходный файл в редакторе на месте, указанном узлом графа. Цель SHALL браться из соответствия ответа ядра (F-18.A, F-19, F-23.A).

#### Scenario: Переход к требованию
- **GIVEN** элемент диаграммы соответствует требованию с доступным исходным файлом и строкой
- **WHEN** человек нажимает на этот элемент
- **THEN** редактор открывает исходный файл на указанной строке

#### Scenario: Переход из снимка обозначает текущее содержимое файла
<!-- F-44 -->
- **GIVEN** из сохранённого снимка выполняется переход к доступному исходному файлу
- **WHEN** редактор открывает рабочий файл на указанном месте
- **THEN** человеку явно обозначено, что редактор показывает текущее содержимое рабочего файла

### Requirement: Переход сохраняет выбранный источник и фильтры
Переход к записи журнала или исходному артефакту SHALL сохранять источник и фильтры вкладки графа (F-22.A, F-23.A).

#### Scenario: Осмотр решения из выбранной части
- **GIVEN** диаграмма построена по выбранным модулю и capability
- **WHEN** человек переходит к записи журнала
- **THEN** вкладка графа сохраняет прежние источник и фильтры

### Requirement: Переход не требует изменения исходных форматов
Связывание клика с целью SHALL использовать соответствие элементов исходным узлам. Поддержка переходов SHALL NOT требовать изменения форматов исходных артефактов и сохранённых графов ради кликов или восстановления адреса по очищенной подписи (F-18.A, F-20, F-23.A).

#### Scenario: Обрезанная подпись
- **GIVEN** длинное имя узла сокращено на рисунке, а ответ содержит соответствие его исходному id
- **WHEN** выполняется переход
- **THEN** выбирается цель из соответствия, формат исходного артефакта и снимка не меняется
