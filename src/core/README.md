# core

Для архивного журнала имя черновика включает закодированный относительный путь изменения. Обычные имена черновиков сохраняют прежний путь. Это позволяет просмотрщику хранить слово человека после адресного открытия журнала из снимка.

Граница с ядром: где ядро — `.symphysis/tools/` проекта или настройка `symphysis.toolsPath`, файлы проекта — изменения, ответы, черновики, события (`project.ts`); поиск и запуск Python (`python.ts`); вызовы `journal.py` и номер контракта (`core.ts`).
