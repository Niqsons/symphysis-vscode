# journal

Логика журнала на стороне плагина, без DOM и vscode: выбор, антиподы, зависимости и промпт возврата (`logic.ts`), правки черновика человеком и счётчики (`ops.ts`), правила режима «атака» (`attack.ts`). Её берут просмотрщик, поиск и дерево изменений.
