# protocol

Внутреннее сообщение страницы `journalPainted` подтверждает готовность DOM указанного журнала для адресного перехода из req-graph. Данные графа и сообщения его отдельной вкладки описаны в модуле req-graph. Публичный ответ ядра для просмотра имеет собственное поле `view_format`.

Общее для хоста и страниц: сообщения между ними, в том числе ответ поиска и разобранная схема (`protocol.ts`), данные `journal.py view-json` и черновик человека (`types.ts`). Типы и умолчания; от других модулей не зависит.
