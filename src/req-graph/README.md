# req-graph

Вкладка графа требований. `graph.ts` проверяет ответ ядра и согласует текущий запрос с успешно показанным рисунком. `graphCore.ts` вызывает публичный `trace view` и проверяет настоящий путь перед открытием файла. `graphPanel.ts` хранит отдельные источник и фильтры каждой вкладки, `page.ts` показывает requirementDiagram, диагностику и список объектов.

Первое открытие предлагает выбрать capability, требование или repo/module. Модуль можно сузить до capability. «Только со связями» скрывает узлы без рёбер внутри выбранной части. Живой граф обновляется кнопкой, до заморозки видна пометка предварительного состояния. Повторное открытие снимка фокусирует его вкладку с сохранёнными фильтрами.
