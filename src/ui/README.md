# ui

Общие части страниц и панелей: текст со ссылками (`Text.tsx`), переключатель (`Segmented.tsx`), цвета (`colors.ts`), тексты отказов (`FailureText.tsx`) и стиль страниц `style.css` — сборка кладёт его в `media/viewer.css`; на стороне VS Code — разметка страницы со строгой CSP (`pageHtml.ts`) и вкладки после перезагрузки окна (`tabs.ts`).
